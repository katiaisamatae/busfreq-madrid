# Frontend — BusFreq Madrid

Frontend React del dashboard (Fase 4). Aún no inicializado.

## Inicializar (cuando llegue la Fase 4)

```bash
cd dashboard/frontend
npm create vite@latest . -- --template react
npm install
npm install recharts leaflet react-leaflet
npm run dev
```

## Funcionalidades previstas

- Selector de línea, fecha y escenario (día normal, lluvia, evento deportivo)
- Comparativa frecuencia actual vs. recomendada (Recharts)
- Tiempo de espera medio antes/después del ajuste
- Mapa de Madrid con capa de calor de demanda por parada (Leaflet)
- Coste incremental en buses del ajuste
